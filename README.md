# 手机小课堂

面向家中长辈的离线安卓入门课堂。1.2 版将全部 22 个非微信课程升级为 HarmonyOS 4.x 风格的练习手机，补齐桌面、设置、图库、聊天和应用市场的逐层操作路径，保留微信 12 课，用图解解释概念，再用本地模拟页面练习。

成品位于 `deliverables/`：调试签名 APK、完整源码压缩包、首页截图及 SHA-256 校验值。验收情况见 [VALIDATION.md](VALIDATION.md)。

安装要求：Android 8.0 / API 26 或以上。归档 APK 沿用相同包名及签名，升级时直接覆盖安装可保留学习记录。建议安装最新的 1.2 版。

## 使用

打开 App，选择课程。每课依次为 **三张图解 → 跟练 → 自己试试 → 完成回顾**，也可以直接进入独立练习。点错后可修改、请求提示或重新开始。首页提供字号设置，并显示本机学习进度。

包含 34 课、102 个图解页面：

- 基础操作：点按/长按、上下滑动、左右翻页、返回/桌面、更多/设置、开关/弹窗。
- 网络与设置：WLAN、移动数据、套餐限额、单个应用联网、权限、通知、音量/亮度、字体、简易/关怀模式。
- 日常软件：输入/删除、搜索、发文字、查看/放大照片、选图发送、扫一扫、安装/卸载。
- 微信专题：四个入口、找联系人、改备注、发文字、发图片、保存图片、语音与上滑取消、语音/视频通话、找聊天记录、群免打扰、置顶、保存和寻找群聊。

非微信课程全部从模拟桌面开始，底部三键分别为返回、桌面和最近任务。返回或切回应用会保留当前连接、开关、字号、照片缩放、输入和安装状态；重新开始、切换课程或进入独立练习才会重新初始化。功能内容在手机内部滚动，跟练区域会高亮当前入口。

WLAN 练习密码为 `12345678`；流量课程使用 2GB 套餐及 0.3GB 模拟下载。权限课程需要先体验拒绝，再到模拟设置允许，以理解两种结果。

微信里的联系人、群和消息都是虚构的。“海阔天空”是示例家人小林，备注课练习改成“家人小林”。微信十二课共用同一套模拟页面，每课、每次重练均从初始数据开始；昵称、备注、聊天排序、未读、图片选择和通知效果在本次练习内联动。

群免打扰课先比较未开启时的提醒，再开启、收消息、进群查看、关闭并再次收消息。普通群消息仍接收，免打扰只改变本课的提醒效果；`@我`、`@所有人`、群公告和通话可能有另外的版本或例外设置。本课不模拟这些细分开关。置顶与免打扰分别管理，保存到通讯录不改变群成员身份。

“模拟收到消息”“模拟来电”等按钮位于微信画面以外，是教学工具。保存图片只写入练习内的模拟相册；语音录音、播放和通话均用图文/状态表示，不申请麦克风或摄像头权限。

字体练习经“设置 → 显示和亮度 → 字体大小与粗细”拖动即时预览，返回观察列表字号；手机长辈关怀与软件关怀分别设置。流量限额经“手机管家 → 流量管理 → 更多流量设置 → 套餐设置”进入，输入 2GB；安装软件后，要回桌面长按新增图标才能卸载。模拟下载、试用联网、来消息和对准二维码均在手机框外的教学区。

界面及路径参考：[华为流量管理指南](https://consumer.huawei.com/cn/support/content/zh-cn15921897/)、[字体与长辈关怀说明](https://consumer.huawei.com/cn/support/content/zh-cn00987051/)。不同版本的名称和入口可能不同，课程提供教学示意。

## 构建

- JDK 21（Java/Kotlin 字节码目标为 17）
- Android SDK Platform 36、Build Tools；最低运行版本 Android 8.0 / API 26
- Gradle Wrapper 9.3.1、AGP 8.13.2、Kotlin 2.3.10

在 `local.properties` 配置本机 `sdk.dir`，或使用 `ANDROID_HOME`。首次构建需要联网获取构建依赖，安装后的 App 完全离线。

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedQaAndroidTest
```

正式试用 APK：`app/build/outputs/apk/debug/app-debug.apk`。1.2（versionCode 3）的包名及调试签名沿用 1.0 / 1.1，可覆盖安装保留本机进度；公开上架需配置自己的发布签名。

设备自动化使用 `qa` 构建类型，包名为 `com.example.phoneclass.qa`，与家庭正式包隔离，测试框架安装/卸载不会清空正式包的数据。不要对家庭正式包执行 `pm clear` 或卸载后重装来升级。

## 代码组织

- `learning/Lessons.kt`、`WechatLessons.kt`：34 课、102 个图解的文案及学习目标；显式稳定课程 ID 与动态分类目录。
- `learning/WechatState.kt`、`WechatEngine.kt`：微信子状态与纯本地状态转换，备注、会话、群设置和图片互相联动。
- `learning/PhoneState.kt`、`PhoneEngine.kt`：独立手机子状态、页面栈、最近任务、内部弹窗和页面上下文校验。
- `learning/PhoneLessons.kt`、`PhonePreviews.kt`：22课路径目标与三张示意图的共用状态；旧课程 ID 保持不变。
- `learning/PracticeEngine.kt`：统一事件分发与完成判断；同时检查路径、操作记录和最终状态。
- `learning/ClassroomModel.kt`：页面状态、跟练到独立练习、重练与进度写入。
- `learning/ProgressRepository.kt`：DataStore 保存课程完成情况、最近位置及字号。
- `ui/ClassroomApp.kt`：首页、图解、练习、完成回顾。
- `ui/PhoneScene.kt`、`ui/Illustrations.kt`：模拟控件和本地矢量插图。图解与练习复用同一套控件。
- `ui/WechatScene.kt`、`WechatCatalog.kt`：连贯微信模拟界面、教学效果预览及重点专题目录。

`src/qa/` 另有仅测试包提供的页面核对 Activity，用同一套手机组件生成代表截图，不读写家庭包进度；正式包仍为单 Activity。

新增课程时需要同时定义讲解和目标、实现对应状态转换与场景 UI，并添加可完成的操作旅程测试。

## 练习边界

所有网络、权限、相机、扫码、软件安装和消息发送均为本地模拟。示例照片使用 Canvas 绘制，不读取真实相册；输入使用系统键盘，文字只存放在本次练习的内存状态。Manifest 不声明网络、相机、存储、通讯录或定位权限，也不包含统计或广告 SDK。

重新开始会清空当前模拟状态，保留已学课程。重新打开 App 后，在首页点继续学习可回到最近讲解页或练习阶段；练习阶段从初始状态重做。手机的系统返回退出练习到图解，模拟导航栏专门用于学习返回和桌面。

华为不同型号的菜单可能不同；本项目提供教学示意，不逐型号还原。较新的原生鸿蒙设备需要单独评估安装兼容性。
